## ⚡ Overview

A bespoke, artisan developer portfolio and engineering showcase built for **Aditya Patra** (2nd-Year B.Tech CSE student at KIIT, maintaining an 8.05 CGPA). 

Designed with an architectural, editorial aesthetic inspired by high-craft engineering portfolios:
- 🏛️ **Architectural Dashed Framing**: Clean dashed borders (`border-dashed`) and Instrument Serif typography.
- 🌊 **Continuous 60 FPS Systems Mesh**: Canvas-based undulating wave and cluster nodes animation.
- ⌨️ **Dynamic Typewriter Subtitle**: Real-time typing and backspacing animation cycling through core domains.
- 🟢 **Real-Time Local Telemetry**: Live local clock (`Asia/Kolkata` IST) and active availability pill.
- 📊 **Sprint-Clustered Activity Graph**: Realistic 52-week GitHub heatmap with organic project bursts and quiet valleys.
- 🖼️ **Visual Project Mockups**: Custom interactive terminal and dashboard previews for every project.
- 🌓 **Zero-Flicker Light / Dark Mode**: Refined Cream (`#fbfbf9`) and Obsidian Charcoal (`#121316`) palettes.

## 💻 Local Setup & Development

### 1. Clone the Repository
```bash
git clone https://github.com/AdityaPatra-dev/portfolio.git
cd portfolio
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Start Local Dev Server
```bash
npm run dev
```
Navigate to `http://localhost:3000` in your browser.

### 4. Build for Production
```bash
npm run build
```
Executes TypeScript type checking (`tsc`) and bundles optimized static assets into `dist/`.

## 🚢 Deployment (Firebase Hosting)

The deployment pipeline is configured via `firebase.json` with SPA routing rewrites:

```bash
# Authenticate with Firebase
firebase login

# Deploy directly to live hosting
firebase deploy --only hosting
```

Live site will deploy immediately to: **[https://adityapatradev.web.app](https://adityapatradev.web.app)**
